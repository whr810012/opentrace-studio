# 演示视频脚本（约 150–180 秒）

1. **开场（10s）**  
   OpenTrace Studio · 赛道一「开源基础软件」· AI 开发工具链  
   像调前端一样调 Agent / RAG。

2. **配置（15s）**  
   引导 → DeepSeek / OpenAI 预设 → Key（打码）。

3. **真跑（35s）**  
   输入问题 → 运行 → 进度与流式 Answer → 时间线增长。

4. **证据（25s）**  
   点 `retriever.local_kb` → 分数与原文 → 再看 llm 入参出参。

5. **失败（20s）**  
   未收录地名 / 错 Key，或「加载 OTLP 样例」看红 `tool.forecast` → 右侧诊断。

6. **Diff（20s）**  
   两次会话 →「对比两次 Run」→ 耗时差、状态、答案摘要。

7. **回放与导出（15s）**  
   自动 / 单步回放 → 导出 JSONL；可提 OTLP / LangGraph / Dify 导入。

8. **收尾（10s）**  
   Apache-2.0 · Key 本机 · 欢迎贡献。

## 录制备忘

- 优先真跑；Key/网络失败立即切「加载离线样例 JSONL」或 OTLP 样例，镜头不停。  
- Key、手机号、邮箱一律打码或裁切。  
- 建议分辨率 ≥ 1280×720，旁白可后期；片尾可叠仓库 URL。  
- 上传后确认「任何人可访问」链接（B 站 / 网盘 / Gitee Release 附件等）。
