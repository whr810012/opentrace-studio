# OpenTrace Studio 操作手册

面向日常使用与演示。安装、安全与协议细节见 README / SECURITY。

## 1. 启动

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:5173`。

生产预览：

```bash
pnpm build
pnpm preview
```

## 2. 界面布局

| 区域 | 内容 |
|---|---|
| 顶栏 | **操作 / 复制 / 导出** 悬停展开菜单后点击执行 · 回放 |
| 左侧 | 会话列表、筛选、离线样例 |
| 中栏 | 问答、统计、时间线、瀑布图、调用图、Diff |
| 右侧 | Live Run 配置与运行；选中 span 的证据与详情 |

## 3. 首次真跑（Live Run）

1. 右侧点 **DeepSeek** 或 **OpenAI** 预设（自动填地址与 Model）。  
2. 粘贴 **API Key**（只存在当前标签页；关掉标签即清）。  
3. 确认地址为 API 根地址，**不要加 `/v1`**。  
4. 输入问题 → **在平台运行并写入 Trace**。  
5. 观察进度、流式 Answer、左侧新会话与中栏时间线。

可选：

- **双模型对比**：勾选后填 Model B，可并行或依次跑，结束后自动打开 Diff。  
- **重跑当前问题**：用当前表单配置再跑活动会话的问题。  
- **停止**：中止进行中的请求。

无 Key 时：左侧点 **加载离线样例 JSONL** 或 **加载 OTLP 样例**，可先熟悉界面。

## 4. 读 Trace

1. 左侧点选会话。  
2. 时间线点某一 span；调用图 / 瀑布图会联动。  
3. 右侧 **Evidence & Detail** 看入参、出参、失败诊断、RAG 片段。  
4. 答案里的 `[1]` `[2]` 可点，跳到对应证据。  
5. LLM span 有 Prompt / Completion 视图，可展开原始 JSON。

常用操作：

- 时间线上方：按 kind、状态、关键词筛选；慢 span 会高亮。  
- 统计区：总耗时、错误数、tokens、粗估成本；点错误可跳首错。若 tokens 为 0，可能是上游流式未返回 usage（界面会提示）。  
- Tokens 线索：时间线 LLM span 可显示 ↑in ↓out；Diff 可看费用差。  
- RAG 快照：顶栏 **复制 → RAG 快照**；导出 MD 也会带质检节。  
- **关键路径**：瀑布图 ◆ 高亮；顶栏 **操作 → 关键路径** 或快捷键 `g` 沿路径跳转。  
- **钉选**：选中 span 后按 `p`，或在钉选列表里跳转。  
- **备注**：中栏备注框，导出报告会带上。

## 5. 回放

顶栏回放条：

- **自动回放** / **暂停** / **单步** / **重置**  
- 倍速：0.5x / 1x / 2x / 4x  
- **断点·错误**（默认开）：落到 error span 暂停  
- **断点·钉选**：落到钉选 span 暂停  

播到末尾后再点自动回放，会从第一条重新开始。

## 6. 对比两次 Run

1. 至少保留两次会话。  
2. 中栏 **对比两次 Run**，选 A / B。  
3. 查看对齐后的耗时差、状态变化、答案摘要与成本差。  

双模型对比跑完会自动打开并选中刚跑的一对。

## 7. 导入与导出

### 导入

| 方式 | 说明 |
|---|---|
| 导入 JSONL / OTLP | 选文件；含 `resourceSpans` 的走 OTLP，否则 JSONL |
| 粘贴导入 | 从剪贴板读文本 |
| 左侧样例按钮 | `offline-pitch.jsonl` / `sample-otlp.json` |
| 分享链接 | 打开带 `#ot=...` 的 URL，确认后加载 |

会话最多保留 20 条；新导入会排在前面，挤掉最旧的。

### 导出（需先有活动会话）

顶栏三个菜单（悬停展开，点击执行）：

| 菜单 | 项 | 用途 |
|---|---|---|
| 操作 | 导入 / 粘贴导入 | 文件或剪贴板导入 JSONL / OTLP |
| 操作 | 主题 / 关键路径 / 快捷键 / 清空历史 | 界面与会话管理 |
| 复制 | RAG 快照 | 复制质检 Markdown |
| 复制 | 复制 JSONL | 剪贴板（`Shift+C`） |
| 复制 | 分享链接 | 写入地址栏并尝试复制；过大请改用导出 JSONL |
| 导出 | JSONL / MD / HTML / CSV | 下载文件（MD 含 RAG 质检节） |

## 8. 快捷键

输入框内一般不触发（Esc 除外）。按 `?` 可打开帮助。

| 键 | 作用 |
|---|---|
| `j` / `↓` | 下一 span |
| `k` / `↑` | 上一 span |
| `h` / `←` | 父 span |
| `l` / `→` | 第一个子 span |
| `e` | 第一个错误 |
| `g` | 关键路径前进 |
| `p` | 钉选 / 取消 |
| `c` | 复制当前 span JSON |
| `Shift+C` | 复制会话 JSONL |
| `/` | 聚焦时间线搜索 |
| `?` | 快捷键帮助 |

## 9. 会话管理

- 列表可搜索；勾选「仅含错误」过滤。  
- 点会话可切换；删除单条或顶栏 **清空历史**（不可恢复）。  
- 数据在本机 `localStorage`；换浏览器 / 清站点数据会丢。

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 连不上模型 | 确认 `pnpm dev`；地址不要带 `/v1`；本机能访问该 API |
| 401 / Key 无效 | 检查 Key 是否完整、是否对应当前厂商 |
| 地理工具失败 | 演示表仅含静安寺 / 徐家汇 / 陆家嘴等；换地名或看红 span 诊断 |
| 分享链接打不开 | 确认弹窗点了继续；过大或损坏会提示忽略 |
| 跨域报错 | 不要绕过本地 `/llm-proxy` 让浏览器直连上游 |
| Key 刷新后没了 | 正常：Key 在 sessionStorage，关标签即清；地址与 Model 会保留 |

更多安全说明见 `SECURITY.md`；OTLP 字段映射见 `docs/OTLP-BRIDGE.md`。
